## 硬性指标

- **词数** 250–300
- **关键词** 恰好 50 个，`**加粗**`
- **密度 ≤ 20%** — 超过 22% 句子会被系统性压坏
- **文体** 经济学人科普社论，必须含具体案例，结尾必须升华

---

## 铁律

英文加粗的重点词，中文译文里对应的译法也必须加粗，中英一一对应。

实现方式：中文按最自然的说法写 → 加粗落在自然说法上 → 后附 `(english)` 括注词源。

## 单词检察官

单文件 HTML，无外部依赖，双击即用。三层结构：

- **第一层** 英文词法句法（20 条正则规则）
- **第二层** 中文译法（9 条）
- **第三层** 篇章与事实（6 条，函数式判断）

会真算的两条：
- `ST-02` 自动提取文中年份算跨度，与"a century / another N years"比对
- `ST-06` 逐个限定词双向查中英对应

界面含密度尺（三区）、段落节奏柱状图、两个样本按钮（定稿 / 病历）。
