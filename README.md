# 记词 · 考研词汇双语读本

《经济学人》风格的双语科普短文，面向考研词汇学习。每篇嵌入恰好50个重点词；英文重点词加粗，中文自然译法同步加粗并保留英文原样括注。网站提供双语阅读、单语阅读、挖空自测、字号切换、打印和1250词索引。

**网站** → https://alienrocketbus.github.io/postgraduate-vocabulary/

## 体式

- 正文：5段。
- 重点词：恰好50个，原则上每段10个。
- 篇幅：新文章优先240—270词；既有锁定稿不因新规则追溯重写。
- 密度：重点词密度不超过20%。
- 跨篇：速查表词元与英文加粗表面形式不得重复；新增文章必须通过全库机械检查。
- 翻译：先写自然中文，再把对应译法加粗并附 `(english)` 括注，不为对齐扭曲中文句法。
- 史实：必须给出具体人名、日期、数字、机制边界和可追溯来源。

## 最终版本铁律

1. 一旦形成新的最终稿、最终精校稿、最终精进稿或锁定稿，必须同步到GitHub `main`；不得只留在对话中。
2. 同步必须覆盖权威数据、生成Markdown、网站、README、交接文档、最终版本manifest、审计记录与sitemap。
3. 前一版本立即作废，只保留在Git历史中；活动文件不得继续承载旧稿。
4. 每篇以 `data/final-version-manifest.json` 的 canonical fingerprint 与 Markdown SHA 为最终身份。
5. `scripts/build_markdown.py` 必须通过结构、中英对应、词数、密度与跨篇去重检查。
6. `scripts/final-version-guard.js` 必须通过最终身份与Markdown指纹检查。
7. 只有合并 `main`、主分支回读正确且CI成功后，才能宣称真正锁定到云端。
