# 考研高价值短语库 —— 可占重点词名额
#
# 立此库之由：单词名额只装得下单词，可考研真正考的东西里，
# 有一大块是**动词短语、固定搭配与介词习语**——
# 它们逐词都认得，合起来却不认得，正是失分处。
#
# 入库判据（四条同时满足）：
#   一 · 真是一个语言单位：整体义 ≠ 逐词义之和，或搭配固定到不可换词
#   二 · 考研真题／真题同源语料里考过或高频
#   三 · 学习者逐词都认得、整体却可能读错
#   四 · 能在本项目的文章里自然用上（非口语俚语、非商务套话）
#
# 用法：正文里整体加粗 **give way to**，速查表算一个名额，
#      释义给整体意思（「让位于」），不许逐词直译。
#
