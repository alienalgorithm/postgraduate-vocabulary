# 每篇文件包

用户 2026-11-16 要求为每篇文章做一个文件包。本目录先做 `01 越狱的章鱼` 一篇作为样品，格式确定后再做其余 69 篇。

## 每个文件包的 7 样

| # | 文件 | 内容 | 怎么做的 |
|---|---|---|---|
| 1 | 视频同屏版.pdf | 与视频画面一致的逐屏讲义：标题、每一句（英文、单词标注、小字说明）、插图、简述 | 直接取自本篇 4K 定稿成片。视频里每句分几段依次点亮，每页取这一屏各段的静止画面，逐像素取最亮的一帧，所以整屏文字都是点亮的，而且每个像素都来自视频本身。颜色按出片程序自己的转换方式解码（背景实测 14,36,29，设计值 14,36,30）。程序会检查屏数等于“标题 + 句数 + 插图 + 简述”，每屏的段数等于源稿的分段数。图片 3840×2160，JPEG 4:4:4，与解码帧相比最低 46.6 dB |
| 2 | 汉译英听写卡.pdf | 左边词性和中文意思，右边横线写英文（单词写原形，短语写词典形式）；最后一页是答案 | 按用户 2026-11-17 要求（“听写卡也改成新词表的形式，要写上词性”），词条与书里文后的新词表完全相同：英文原形、词性、贴合本文语境的词典式释义，按段落、按原文先后，同篇原形和词性相同的已合并 |
| 3 | 英译汉听写卡.pdf | 左边英文原形和词性，右边横线写中文意思；最后一页是答案 | 同上 |
| 4 | 逐句精讲.pdf | 每句：原句与视频译文、句子主干、成分划分、结构分析（逐层拆）、语法点（难点配文外例句）、知识点、译法提示；开头有全文脉络 | 先写稿，再由另一组独立审校逐字段核对改正（核对记录见 `核验/corrections.json`），最后由程序检查 |
| 5 | 单词精解册.pdf | 每个重点词：英美音标、词性、本文意思（视频原文）、文中形式、本文语境、词源构词、常用义项、常见搭配、用法详解、近义辨析、同根词、文中例句（附视频译文）、文外例句 | 同上；美式音标另用 CMU 发音词典自动比对辅音和重音 |
| 6 | 阅读版.pdf | 本篇在《考研学人》v5 里的那一章：插图、原文、译文、词汇与表达、文章简述 | 与书同一套程序、同一份数据单独排出，逐页文字与书中这一章相同 |
| 7 | 视频.mp4 | 本篇 4K 定稿成片 | 与 `视频修订定稿/最终定稿/视频/01 越狱的章鱼.mp4` 同一个文件（SHA-256 b2f2dbff…a874） |

全部 PDF：不用粗体；不用破折号；中英文混排时英文用 Source Serif 4，中文用 Noto Serif SC，音标用 Noto Serif（字体都是开源 OFL 许可）；每份都加了默认隐藏的“来源署名｜朋克英语”图层，默认显示与未加时逐像素相同。

## 01 越狱的章鱼：核对结果

- 视频同屏版 19 页：标题 1、句子 16（分段数 4,4,1,2,1,1,2,2,3,1,2,3,2,2,1,2 与源稿一致）、插图 1、简述 1。
- 听写卡：各 63 条，各 4 页（含答案页）。2026-11-17 起 70 篇听写卡都按新词表重做，共 4231 条，与书中词表逐条相同；每条原形和释义都在 PDF 中核对到。
- 逐句精讲 32 页：16 句的成分划分拼起来与原句逐字相同；每个难点都有文外例句，例句都不取自原文。
- 单词精解册 54 页，63 个词：
  - 本文意思直接取视频中文。
  - 文外例句都不取自原文。
  - 美式音标与 CMU 词典比对，只提示 3 处，人工确认都对：bristly、sentient 词典未收；wholly /ˈhoʊlli/ 双写 l 是牛津词典的标法。
- 审校改正 61 处，主要是：
  - 词源表述按 Etymonline 收紧或删除无据说法。
  - “Inky 回到了大海”改为推测语气（原文用 presumably）。
  - 换掉一个没示范到对应语法点的例句。
  - 补美式读音。
- 规则检查：没有破折号、Markdown 记号和“怎么理解”一类说法。

## 重建

`制作程序/` 下的脚本按顺序跑：`prep.py NN`（文章数据）→ `screens.py`（视频同屏版）→ `cards.py`（两张听写卡）→ `reading.py`（阅读版）→ `content-workflow.js`（精讲与单词的写稿和独立审校）→ `jiangjie.py`、`cidian.py`（排版）→ `ipa_check.py`（音标比对）→ `stamp.py`（署名图层）。脚本里的路径是本次制作环境的路径，换机器时改开头几行即可。
