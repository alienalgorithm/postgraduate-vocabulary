# 05 · The Price Was Elsewhere

> 题材：UPC 条形码与零售信息基础设施

## 英文正文

On 26 June 1974, a **cashier** at a Marsh supermarket in Troy, Ohio, passed a **humble** 67-cent pack of Wrigley’s Juicy Fruit over a Universal Product Code (UPC) **scanner**. The scanner read neither name nor price. Yet the **purchase** was **historic**: the first **retail** transaction recorded by scanning a UPC. The **invention** came earlier; **negotiation** and **coordination** made scanning **ordinary**.

In 1949 Norman Woodland and Bernard Silver applied for a **patent** on an **optical** system to **classify** **goods** using printed marks. The 1952 document **depicted** linear and **circular** patterns. The **concept** was **feasible** in principle but **premature**: lasers did not exist, **computing** was costly and no common code spanned the industry.

By 1970 grocers had agreed on a product code but not a machine-readable **symbol**. IBM **engineer** George Laurer’s team proposed **vertical** bars because a bull’s-eye was **vulnerable** to ink spread. A **committee** **selected** IBM’s **proposal** in 1973. The UPC-A **format** turned a 12-**digit** **identifier** into geometry; the final figure helped catch misreads.

In Troy, a **mirror** swept a **laser** **beam** over the label. A photodiode **detector** measured the **reflected** light; the system **translated** bar-and-space **widths** into a number.

The gum’s code carried neither **description** nor price. A database **provided** both, allowing price changes without reprinting packages. Each sale could update **inventory**. Machinery alone was no system. Stores **maintained** records, **vendors** built **compatible** readers and manufacturers printed codes. A **proprietary** system might serve one chain; **infrastructure** required **competitors** to follow one **specification** within an industry-wide numbering system. At checkout, the system’s **elegance** was **apparent** and the **consensus** behind it invisible: the bars held the number, while the price was elsewhere.

## 中文译文

> 铁律：英文加粗词在中文里对应的译法同样加粗，后附 `(english)` 括注词源。
> 中文按最自然的说法写，加粗落在自然说法上——不为对齐扭曲句法。

1974年6月26日，在俄亥俄州特洛伊市的一家Marsh超市，一名**收银员**(cashier)把一包售价67美分、**不起眼的**(humble)箭牌“黄箭”口香糖从一台通用商品代码（Universal Product Code，UPC）**扫描器**(scanner)上方划过。扫描器既没有读出商品名称，也没有读出价格；但这笔**购买**(purchase)依然**具有历史意义**(historic)：它是第一笔通过UPC扫描记录的**零售**(retail)交易。那项**发明**(invention)出现得更早；真正让扫描结账变得**平常**(ordinary)的，是行业内的**协商**(negotiation)与**协调**(coordination)。

1949年，诺曼·伍德兰和伯纳德·西尔弗为一套**光学**(optical)系统申请了**专利**(patent)；这套系统利用印刷标记来**分类**(classify)**商品**(goods)。1952年的专利文件**描绘了**(depicted)直线和**圆形**(circular)图案。这一**构想**(concept)在原理上**可行**(feasible)，却**为时过早**(premature)：当时激光尚未问世，**计算技术**(computing)成本高昂，行业也没有通用代码。

到1970年，食品零售商已经就商品代码达成一致，却还没有共同认可的机器可读**符号**(symbol)。IBM**工程师**(engineer)乔治·劳雷尔带领的团队提出使用**纵向的**(vertical)条纹，因为靶心图案**容易受油墨扩散影响**(vulnerable)。1973年，一个行业**委员会**(committee)**选中了**(selected)IBM的**方案**(proposal)。UPC-A的**格式**(format)把一个12**位**(digit)**识别码**(identifier)转化为几何图形；末位数字则帮助发现误读。

在特洛伊的那套设备中，一面**反射镜**(mirror)使**激光器**(laser)发出的**光束**(beam)扫过标签。一只光电二极管**探测器**(detector)测量标签**反射的**(reflected)光；系统再把条纹与间隙的**宽度**(widths)**转换成**(translated)编号。

这包口香糖的代码既不含商品**描述**(description)，也不含价格；两者由数据库**提供**(provided)，因此改价无需重印包装。系统还可根据每笔交易更新**库存**(inventory)。但机器本身还称不上一个系统。商店**维护**(maintained)商品记录，设备**供应商**(vendors)制造与统一编码**兼容的**(compatible)读取器，制造商则印上代码。一套**专有的**(proprietary)系统或许能服务一家连锁企业；要让它成为**基础设施**(infrastructure)，彼此**竞争的企业**(competitors)就必须遵循同一套**规范**(specification)，并使用行业统一的编号体系。到了收银台前，系统的**精巧之处**(elegance)**显而易见**(apparent)，支撑它的行业**共识**(consensus)却藏在幕后：线条里存着编号，价格则在别处。

## 史实核对

以下关键信息已据所列来源核对：

- 1974年6月26日，俄亥俄州特洛伊市的Marsh超市启用了首批UPC扫描器；一包售价67美分的Wrigley’s Juicy Fruit口香糖成为第一笔由UPC读取的零售购买。本文没有把它写成“人类第一次扫描条形码”，因为其他自动识别系统此前已经投入试验。
- Norman Joseph Woodland与Bernard Silver于1949年申请、1952年10月7日获授美国专利2,612,994。专利同时描述了直线与同心圆图样；它是条形码的早期基础概念，并非1973年最终采用的UPC本身。
- 到1970年，美国食品零售业已经先行确定一套十位商品编号，随后才征求把编号交给机器读取的统一符号。1973年的精确采用日期在IBM与GS1资料间略有差异，因此正文只写年份。入选的矩形符号由George Laurer领导的IBM团队开发，选择与标准化则由行业委员会完成。
- UPC-A承载12位GTIN-12商品识别码，末位是按前11位计算得出的校验位。它能帮助发现误读，但不能保证识别所有错误，也不是单件商品的序列号。
- 特洛伊市首批设备由Spectra Physics提供激光扫描器、NCR提供计算机收银机。激光经旋转镜面扫过标签，反射光由光电二极管检测，收银系统再到存储的商品数据库中检索信息；本文没有把整套结账硬件归功于IBM。
- UPC通常只编码稳定的商品标识，不直接存放商品名称或价格；这些可变信息由零售商的数据库返回，因此改价不必重印商品代码。销售记录可以支持库存管理，但这一收益依赖制造商、零售商与设备商逐步采用同一规范，并非1974年一次扫描就立即实现。
- 跨企业通用还需要统一的编号管理。Uniform Product Code Council于1974年被指定管理这一体系，后来才更名为Uniform Code Council；正文将这一点概括为“行业统一的编号体系”，没有把商品编号全部归于单一机构，也没有把基础设施归结为某一种条纹图案或某一家公司的单独发明。
