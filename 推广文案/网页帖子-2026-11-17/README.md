# 网页图文帖子（2026-11-17）

用户要求：做一篇发在网站上的图文帖子，整体介绍全套资料，讲清每个文件的作用和具体用法，多放展示图（贴合网页，不用 1:1），标题要特别吸引人；作者只说是 B站UP主。

- `post.md`：帖子正文（Markdown，配图写作 images/xx.png）。
- `post.html`：排好版的网页预览，用浏览器打开就能看到最终效果（配图用 images/ 里的 JPG）。
- `post.txt`：纯文字版，给不支持 Markdown 的网站用；配图位置写成【配图：xx.jpg】。
- `images/`：11 张配图，宽 2160 像素（网页按 1080 显示），PNG 原图和压缩过的 JPG 各一份。
- `制作依据/`：写文案和做图时用的事实清单、设计规范、70 篇标题。

发布前把正文里的【价格】和【购买链接】换成实际内容。

制作过程：三个角度各写一稿，主编合稿，逐条核对事实；9 张图各由一人制作、另一人独立审查修改；第一轮总审发现阅读版的词表还是旧格式（已重排 70 份阅读版并核对与教材逐页相同）和若干图文问题，第二轮全部改正并复查通过。
