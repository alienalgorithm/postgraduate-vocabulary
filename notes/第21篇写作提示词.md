## 一、你要达到的标准

写第21篇。**唯一的成功判据**：一个受过大学或研究生教育的英文母语者读完，
会觉得这是一篇**真正好的文章**——不是"给中国学生练词汇的材料"，
而是他自己愿意读完、读完还记得的东西。

合规分 100 是及格线，不是目标。**合规保证不了好，只保证不烂。**

## 二、动笔前必须做的三件事（顺序不能反）

### 1. 先重读三篇正文，不是读规范文件

```
读 articles/17-the-few-that-came-back.md
读 articles/12-the-blank-was-not-blank.md
读 articles/02-a-garden-without-sunlight.md
```

**目的是摸清句子怎么接续、每段承担什么活**，不是记规则。
（上一次第21篇被淘汰，根本原因就是没重读正文就开写。）

### 2. 选题必须满足四条

- **有一次真正的反转**：读者以为是 A，证据指向 B。没有反转的题材是编年，不是文章。
- **有一组判别性证据**：能在两种解释之间做出判决的那个数字或那次实验。
- **有具体的人在做事**：人名、日期、地点。不能是"科学家们发现"。
- **有可查来源**：每个数字都要能给出处。

### 3. 先跑词池，再动笔

```bash
# 把研究笔记写成 notes.txt，然后：
python3 scripts/agent.py brief notes.txt
```

它会给出四组词：**可用高价值词 / 题材必需的生僻词 / 必须避开（含同根）/ 白送词**。

**从"可用"那一组里挑满 50 个。** 绝不能写完再查重——
撞车就得重写整句（这条是缺陷库 PR-02，血泪教训）。

## 三、五段功能骨架

| 段 | 任务 | 范例（第17篇） |
|---|---|---|
| **§1 布景与装置** | 谁、何时、何地、用什么。末句抛出触发点 | 1909年曼彻斯特暗室、放射源、铅屏、荧光屏，末句是那道闪光 |
| **§2 异常本身** | **反常事实与"为什么这反常"必须同段出现** | 多数穿过、少数折返；"考虑到动量，这种掉头令人震惊"就在同一段 |
| **§3 当时的解释为何不够** | 摆出主流模型，指出它解释不了什么。这是论证的支点 | 汤姆孙原子每次只给微弱一推；卢瑟福的分析要求一次强冲量 |
| **§4 判别性证据** | 能做出判决的那组数字。通常最长，是引擎 | 盖革-马斯登1912—13年的定量测量检验了角分布预言 |
| **§5 意义与升华** | 先给可迁移的一般命题，再用一句具体的话收束 | "让少数折返者推翻多数看似证实的模型" |

**每段 10 个重点词、约 50—58 词。正文只让事实推进，判断留到 §5。**

## 五、必须避开的十四个坑（全是本项目实际犯过的）

### 结构类

1. **句子不能出现得太早。**
   一句话如果它的回报（它解释的、它铺垫的）在两段之后才出现，它多半来早了。
   *实例*：第02篇「船上没有生物学家」原在 §1，横在两句 ANGUS 中间，
   前后都接不上；移到 §3 开头作为「所以没人说得出这些动物吃什么」的原因，才对。

2. **连接词必须真的成立。**
   *实例*：第13篇「基因从没动过；**所以**每一块色斑都是一只钟」——推不出来。
   钟成立靠的是 Ds 离开的**时刻**，与"基因没动"无关。

3. **抽象不能跑在具体前面。**
   一般性结论要等事实说尽才出现。
   *实例*：第19篇原为「说go → 韧性系统的结论 → 燃料只剩25秒」，结论夹在两个事实中间。

4. **段落接缝不能断档。**
   §n 末句要把东西交给 §n+1 首句。
   *实例*：第15篇「电控对手赢了试验」→「科芬推动立法」，中间缺
   「造得出不等于装得上：铁路只在划算的地方才装」这一拍。

5. **结尾两句格言不能相邻。**
   **解法不是插一句无关事实**（我犯过，一次造出五处硬塞），
   而是：合并成一句，或让其中一句带上具体事实（数字/专名）。

### 中文类

6. **不能为对上英文而挤出单字。**
   *错*：就**溶**在群落周围 → *对*：**溶解**在群落周围的水里
   （氢、氯、碳、阀、缸这类本就成词的单字不在此列）

7. **一个中文词不能拆成两个英文名额。**
   *错*：这个奖不**追**(posthumously)**授**(awarded) → *对*：这项**荣誉**从不**追授**
   *错*：气压**骤**(sudden)**跌**(slump) → *对*：**骤然****垮掉**

8. **中英语序不同是正常的，不要为对齐而扭曲中文。**
   `a **physician** who lived **nearby**` ↔ `住在**附近**的**内科医生**`——顺序相反是对的。

### 英文类

9. **抽象名词不能作主语**（写作规范 §3.3）。
   *错*：Rutherford's **analysis** required… → *对*：**Rutherford** showed…
   *错*：The **discovery** was collective → *对*：**Three men** made it collective

10. **被动语态可以用，但要有施事。**
    `The circular was **signed** by Pickering` 是好的——它正要突出署名者不是她。
    `It was done / made / kept` 这类藏起施事的才是问题。
    参照：优秀说理散文被动率 **22.4%**，不必刻意回避。

11. **句长要有节奏。**
    参照语料均长 21.2、标准差 12.0；本体裁受词数约束达不到，
    但**不能三个 7—9 词的短句连排**——那读起来像一句一句往外蹦。

### 事实类

12. **不采用流行谣言，哪怕它更好听。**
    *实例*：第03篇不写"NASA删除了异常数据"。真相更强：
    TOMS 把低值标记待查，团队拿南极点地面记录去核对，
    **可那份记录本身就是坏的**——该来核对的那把尺子自己坏了。

13. **给数字，不给形容词。**
    *错*：H4 的表现"看上去不错" → *对*：81天慢了5.1秒，误差不足1海里，而容许30海里

14. **补进的事实必须同时进 facts 块并附来源。** 数字最容易在改写中飘走。

## 六、上一篇第21篇为什么被淘汰

写的是彗星客机（1954年）。失败原因，逐条记下以免重蹈：

- **§2 写成了新闻报道式**，而前二十篇的正文是**机制密度式**——每句把一个名词交给下一句。
- **重点词选了评论词**（hazard / careless / total / verdict），而不是承重技术词
  （differential / fissure / oxidise / fuselage）。
- **评论语句散落在正文各段**（"Water, not air:" / "De Havilland had not been careless"），
  这些应当全部留到 §5。
- **逐句估词系统性低估**：初稿317词，我预估265词（缺陷库 PR-01）。

## 七、写作与交付流程

```bash
# 1. 研究笔记 → 可用词池
python3 scripts/agent.py brief notes.txt

# 2. 写英文五段（先写自然英文，再挑承重词加粗）
#    写中文（先写自然中文，再落加粗与括注）

# 3. 草稿体检：计量、分布、冲突、修改指令
python3 scripts/agent.py review draft.md

# 4. 入库后让机器出题，逐题作答
python3 scripts/agent.py audit 21

# 5. 推送前一次过（含 CI 独有的那一步）
python3 scripts/preflight.py
```

### 编辑纪律（这条救过我六次）

**改任何一处之前，先把真实文本读出来，再做替换，并用 assert 校验。**
不要凭记忆构造匹配串——我按记忆猜中文原文，一次同时改坏三篇。

### 指标改动要同步三处

1. `data/*.js` 的 metrics
2. `scripts/final-version-guard.js` 里 README / 交接文档的行校验
3. `.github/workflows/validate-content.yml` 里 16—20 篇的硬编码期望值 ← **本地跑不到**

## 八、什么时候算写完

**临界点判据：改一处若要牺牲另一处（论证、中文、词价、指标），就是到位了，停手。**

不是"合规分100"就算完。合规分只说明没犯规。
到位的标准是：**再动就要拿走一样别的东西。**
