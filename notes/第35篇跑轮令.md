## 二、这一篇的骨架（改动不得伤到它）

**反转**：菲茨罗伊造出风暴预警，并为它造了 forecast 这个词。
他死后，一个评审席把预警与公众预报**一并停掉**。

**判别性证据 · 一次天然实验**：同一份裁断停掉两样——
**海上那一样，十三个月就被要了回来；报纸上那一样，等了十三年。**
这个差值量出的不是科学水准（评审席对二者判词相同），而是**当时有谁在依赖它**。

**另一半证据**：评审席的构成——**没有一名气象局人员，没有一个支持者**。

**收束**：一样是被倚仗着的；另一样，只是被扫过一眼。

> **凡改动，先问：它伤到上面哪一条了吗？伤到就退回。**

## 十、六条不许碰的红线

1. **不为词数而伤史实**（第14篇差点删掉 `almost three degrees` 的 almost）
2. **改了英文必须回读中文**，且**中文写完反过来校英文**
3. **标题实词必须在正文有落点，且与收束句所指一致**
   （`Thirteen`／`Months`／`Years`，已查过，别改丢）
4. **绝不整表重建速查表**——表存词根、正文用屈折形式，已栽六次
5. **改动与校验分开跑**——断言失败会让整批编辑不落盘
6. **重建速查表必须带断言**：
   ```python
   assert any('\u4e00' <= c <= '\u9fff' for c in z), (aid, k, z)
   ```
   **没有它，`or w` 的 fallback 会把英文词写进中文栏且不报错。**
   （**本篇入库时，断言当场拦下两处**：`thirteen` 数词加粗、`**One report**` 双词加粗。）
