# 单篇精修提示词 · 八轮到临界点

> 用法：把本文件全文发给 Claude，并在开头写明篇号，例如「精修第21篇」。
> 每轮只查一层，层与层不重叠。跑完八轮再判定是否到临界点。

---

## 总规则

**目标不是「改好」，是「改到不能再改」。**

临界点的定义：**再动一处，就必须拿走另一样东西**（论证力、中文可读性、词价、
史实准确、或某项硬指标）。到了这个位置就停手，并写明是哪一样东西挡住了。

**三条纪律，每轮都适用：**

1. **改之前先把真实文本读出来。** 用 node 从数据层取出该段的 en/zh 原文，
   再做替换，并用 `assert` 校验匹配。**不要凭记忆构造匹配串**——
   本项目曾因此一次改坏三篇。
2. **每轮结束必须回跑** `python3 scripts/inspector.py <篇号>`，
   确认没有为修一处而碰坏另一处（约三分之一的新缺陷是修改引入的）。
3. **每轮都要报告三件事**：这一轮改了什么、什么没改、为什么没改。
   「没改」的理由和「改了」同样重要——它是临界点的证据。

---

## 第一轮 · 机器层

把所有工具跑一遍，机器能判的先清干净。

```bash
python3 scripts/inspector.py <篇号>      # 九层规则
python3 scripts/agent.py audit <篇号>    # 审读任务书
python3 scripts/preflight.py             # 含 CI 独有那一步
```

**处理顺序**：阻塞项 → 结构 → 词价 → 需人工判断。
**注意**：`待核`与`提示`不是必改项。逐条判断，判定为「合理」的要写明理由，
不要为了消掉告警而牺牲文章（本项目曾为消 STR-03 硬插五句无关事实）。

**本轮完成的标志**：硬伤 0，且每条待核都有「改」或「保留+理由」的处置。

---

## 第二轮 · 句序层：有没有句子来得太早

**逐段逐句问**：这句话的回报——它解释的、它铺垫的东西——出现在哪里？

- 回报在同段后几句 → 正常
- 回报在下一段 → 可接受，但要确认它不是插在两句紧密相连的句子中间
- **回报隔了两段 → 它多半来早了**

**判据**：如果一句话删掉后，前后两句反而接得更紧，它就是横插进来的。

> **实例**：第02篇「船上没有生物学家」原在 §1，夹在两句 ANGUS 之间。
> 前一句讲 ANGUS 被拖行，后一句讲 ANGUS 记录到温度骤升——**它谁也接不上**，
> 而它的回报（「所以没人说得出这些动物吃什么」）在 §3。
> 移到 §3 开头后，它从伏笔变成原因，还顺手把 §3 原本孤立的三句串成因果链。

**修法**：不是删掉，是**移到它的回报旁边**，让它从伏笔变成原因。

---

## 第三轮 · 接缝层：段与段之间断没断

把四处接缝拉出来对读：§1末→§2首、§2末→§3首、§3末→§4首、§4末→§5首。

**问**：后一句是否承接前一句交给它的东西？前一句的名词、动作、悬念，
在后一句里有没有落点？

**好的接缝长这样**：
- 第02篇「这份繁盛找不到来源」→「后来的研究把来源找到了」
- 第11篇「静止地搁在管里，什么也没有」→「让铜盘在磁极间旋转」
- 第04篇「误差不到一海里，而容许三十」→「评审委员们迟疑了」

> **断档实例**：第15篇「电控对手赢了试验，但他判断接线撑不住货运」
> →「爱荷华的改革者洛伦佐·科芬推动立法」。从技术判断直接跳到立法游说，
> 中间缺「造得出不等于装得上：铁路只在划算的地方才装」这一拍。

**修法**：补一句桥，或改写后一句的开头使其承接。**补的桥必须是实质内容，
不能是过渡废话。**

---

## 第四轮 · 因果层：连接词真的成立吗

找出全篇所有的 `so / therefore / thus / because / that is why / 所以 / 于是 / 因此`，
逐个验证：**前一句真的推得出后一句吗？**

> **实例**：第13篇「基因从没动过；**所以**每一块色斑都是一只钟。」
> 推不出来——钟能成立靠的是 Ds 离开的**时刻**，与「基因没动」无关。
> 改为真链条：「Ds 可以在籽粒发育的任何时刻离开，而每一块色斑都标出了是哪一刻。」

**顺带查两件事**：

- **抽象有没有跑在具体前面**？一般性结论要等事实说尽才出现。
  （第19篇原为「说go → 韧性系统的结论 → 燃料只剩25秒」，结论夹在两个事实中间。）
- **末段两句格言是否相邻**？解法**不是**插一句无关事实，
  而是合并成一句，或让其中一句带上具体事实（数字/专名）。

---

## 第五轮 · 中文层：中文自己站不站得住

**把中文单独读一遍，遮住英文。** 问：这是一段中国人会写的中文吗？

四类必查：

1. **为对上英文而挤出的单字**
   *错*：就**溶**在群落周围 → *对*：**溶解**在群落周围的水里
   （氢、氯、碳、阀、缸这类本就成词的单字不在此列）

2. **一个中文词被拆成两个英文名额**
   *错*：这个奖不**追**(posthumously)**授**(awarded)
   *对*：这项**荣誉**从不**追授**（改英文用词，让一个中文词只对一个英文词）

3. **搭配错、结巴、秃尾**
   指针**蹬**了一下（蹬是腿脚的动作）→ 猛**弹**了一下
   在那个村子**外围****围**了一圈（结巴）→ 绕着那个村子**围**出一圈
   记天气，然后**等**。（秃）→ 然后**等着**。

4. **不要为对齐而扭曲语序**
   `a **physician** who lived **nearby**` ↔ `住在**附近**的**内科医生**`——顺序相反是对的。

**机器辅助**：`inspector` 的 ZH-01 会列出所有单字加粗，ZH-02 会报疑似拆词。
但白名单之外的单字**需逐条人工判**，多数是好的。

## 第六轮 · 词价层：每个名额都配得上吗

50 个名额是稀缺资源。逐词问：**一个考研考生学到这个词，值不值？**

- **Zipf ≥5.0 一律不合格**（`inspector` 会报）——考生早已掌握，占名额等于浪费
- **Zipf 4.6—5.0 的边缘词**：能换则换，换不动要说明为什么它必须在
- **专名内部不许加粗**（`Galápagos **Rift**` 是错的）
- **同一段内相邻的两个加粗词**：确认不是一个词条被拆成两个名额

**换词时必须先查冲突**：

```bash
python3 -c "
import sys; sys.path.insert(0,'scripts')
from agent import load, used_index, norm, stem, kin
from wordfreq import zipf_frequency as z
arts=load(); exact,stems,owner=used_index(arts,'<篇号>')
def chk(w):
    if norm(w) in exact: return owner.get(norm(w))
    if stem(w) in stems: return owner.get(stem(w))
    ak=[k for k in exact if kin(w,k)]
    return owner.get(ak[0]) if ak else None
for w in '候选词1 候选词2 候选词3'.split():
    h=chk(w); print(f'{w:14}{z(w,\"en\"):>5.2f}  {\"✗第\"+\"、\".join(sorted(h)) if h else \"✓\"}')"
```

**含同根**——`return` 用过则 `returns/returned/returning` 全封。

## 第七轮 · 母语者层：像不像好英文

把英文单独读一遍，标准是：**一个受过研究生教育的英文母语者读完，
会不会觉得这是一篇真正好的文章。**

**可以对标的实测数据**（`data/reference/prose-profile.json`，
取自 NLTK Brown 语料说理散文 41.7 万词）：

| 指标 | 优秀说理散文 | 说明 |
|---|---|---|
| 句长均值 | 21.2 | 本体裁受 270 词约束，达不到，不必强求 |
| 句长标准差 | 12.0 | **但不能三个 7—9 词的短句连排**——那读起来像一句一句往外蹦 |
| 被动句占比 | 22.4% | 被动不是错。**带 by 施事的被动是好的** |
| 长句(>34词)占比 | 12.9% | 说明长句本来就该有 |

**必查三项**：

1. **抽象名词作主语**（`inspector` SYN-04 会报）
   *错*：Rutherford's **analysis** required… → *对*：**Rutherford** showed…
   *错*：The **discovery** was collective → *对*：**Three men** made it collective
2. **藏起施事的被动**：`It was done / made / kept` 是问题；
   `The circular was signed by Pickering` 是好的——它正要突出署名者不是她。
3. **句长节奏**：短句连排的地方，合并成一长一短。

**搭配地道性**：机器判不了（本项目试过 446 万词语料建搭配库，
`foul air`、`medical opinion` 这类完全地道的搭配都被误报，路径已作废）。
这一项只能靠读。**读出别扭就改，改不动就记下来。**

## 第八轮 · 临界点判定

把前七轮所有「没改」的项目列成一张表，逐条回答：

| 项 | 为什么没改 | 改了会牺牲什么 |
|---|---|---|
| 例：句长均值 14.6，低于语料 21.2 | 体裁约束 | 270词上限 + 50重点词，拉长句必然挤掉论证或重点词 |
| 例：低频词密度 22.8%，高于语料 13.3% | 体裁目的 | 重点词本就是要教的生词，降下来就没有教学价值了 |

**判定为到达临界点的条件**：表中每一项都能指出「改它要牺牲什么」。
只要还有一项答不上来，说明还没到，回去改。

**最后交付**：

1. 八轮各自的「改了什么 / 没改什么 / 为什么」
2. `python3 scripts/preflight.py` 全绿输出
3. 一句话结论：**这篇已到临界点，挡住它的是 ______**
