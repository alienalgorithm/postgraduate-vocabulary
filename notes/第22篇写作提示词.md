## ★ 最高原则：文章质量优先于选词

**没有预设词表。词从题材自身来。**

50 个加粗名额是**从写好的文章里挑出来的**，不是先定词再凑文章。

**当一个词被判为白送词（Zipf ≥5.0）时，正确处置是：
取消它的加粗，把名额让给同段另一个词——不要为避开它而改动英文。**

自然的说法留在正文，只是不占名额。

> **实证（第23篇）**：我为避开 Zipf 做过五处替换，事后全部退回：
> `blood groups` → `blood antigens`（1980年代法庭说的就是 blood groups）
> `kitchen hand` → `scullery worker`（scullery 是维多利亚时代的词，1986年不用）
> `for nothing` → `idly`（idly 是「懒散地」，不是「无端」）
> `asked for help` → `asked for assistance`（公文腔，而这里是警察开口求人）
> `an X-ray film` → `an X-ray negative`（film 更自然）
>
> **其中两处还伤了史实准确度。** 五处的共同点：为了一个词价指标，
> 把母语者会说的话改成了别的说法。

**唯一的词汇硬约束是跨篇不重复（含同根）**——它不会扭曲英文，
因为撞车时可以改加粗别的词，不必改句子。

## 二、动笔前四件事（顺序不能反）

### 1. 重读三篇正文

```
articles/17-the-few-that-came-back.md
articles/21-they-never-held-the-same-foot.md
articles/12-the-blank-was-not-blank.md
```

**目的是摸清句子怎么接续、每段承担什么活**，不是记规则。
上一次第21篇候选被淘汰，根本原因就是没重读正文就开写。

### 2. 选题四条，缺一不可

- **有一次真正的反转**：读者以为是 A，证据指向 B。没有反转的是编年，不是文章。
- **有一组判别性证据**：能在两种解释之间做出判决的那个数字或那次发现。
- **有具体的人在做事**：人名、日期、地点。不能是"科学家们发现"。
- **有可查来源**：每个数字都要能给出处。

> **判别性证据的范本**（第21篇）：瓦萨号沉没，几百年来问「该怪谁」。
> 而船上打捞出**四把木工尺**——两把瑞典尺一尺十二寸，两把阿姆斯特丹尺一尺十一寸。
> 这一组物证直接在「国王的错」和「没有共同标准」之间做出了判决。
> **好的判别性证据是可以被复述的一件具体的东西，不是一段论证。**

### 3. 词池

```bash
python3 scripts/agent.py brief notes.txt
```

从「可用」组里挑满 50 个。**绝不能写完再查重**——撞车就得重写整句。

### 4. ★ 词池选词后的自然度复核（本版新增）

**词池只告诉你哪些词「可用」，不告诉你哪些词「自然」。**

对每个准备用的词，再问一遍：**母语者会用这个词说这件事吗？**

> **第21篇的教训**：`deck` 作为加粗词与第04篇冲突，我改用了 `planking`。
> 技术上没错，但**人在甲板上跑，不在「铺板」上跑**——planking 指船板这个材料。
> 十一轮才发现。

**关键认识：冲突只约束加粗名额，不约束正文用词。**
`deck` 不能加粗，但可以不加粗地用；第21篇 §3 的 `a second gun deck` 本就在用。
**先写出自然的句子，再从中挑能加粗的词——不要为了凑名额而扭曲用词。**

## 三、五段功能骨架

| 段 | 任务 | 第21篇示例 |
|---|---|---|
| **§1 布景与触发** | 谁、何时、何地、出了什么事 | 1628年8月10日起航，三面帆，64门炮，两阵风，1300米，三十人溺亡 |
| **§2 异常本身** | **反常事实与「为什么这反常」必须同段** | 毛病早在港内就露过：三十人跑甲板，弗莱明叫停试验，却没人取消航行、没人告诉国王 |
| **§3 当时的解释为何不够** | 摆出主流说法，指出它解释不了什么 | 归咎国王解释了重心过高，解释不了为何偏向左舷 |
| **§4 判别性证据** | 能做出判决的那组事实，通常最长 | 霍克三年丈量每块板，左舷结构多于右舷 |
| **§5 意义与升华** | 一般命题＋一句带具体指涉的收束 | 四把尺→每个人量得都对→across that hull, no two held the same foot |

**每段 10 个重点词、46—60 词。正文只让事实推进，判断留到 §5。**

---

**★ 词数：270 是上限，不是目标。**
文章在论证说完的地方结束，不在计数器说 270 的地方结束。
下限 250（50 词在 240 词下密度 20.8%，已破 20% 上限）。

> 实证：23 篇里 21 篇落在 267—270 这四个词的区间内。
> 没有哪个人类作者会这样——**那是机器痕迹**，
> 成因是把「合规」当成了「完成」的信号：写超了削到 270 就停，从不问还能不能再削。
> **写完必跑减法轮**：逐词问「删掉它，读者会不会觉得少了东西」，
> 落在哪个词数就是哪个数。

## 四、硬约束

| 项 | 要求 |
|---|---|
| 词数 | **240—270** |
| 重点词 | **恰好 50**，分布 **10·10·10·10·10** |
| 密度 | ≤20%，单段局部 ≤22% |
| 段落 | 5 段，每段 46—60 词 |
| 词价 | **零白送词**（Zipf ≥5.0） |
| 跨篇 | 与前 21 篇 1050 词零重复，**含同根** |
| 中英对应 | 每个英文加粗词，中文必须有对应加粗 + `(english)` 括注 |
| 数字 | 正文每个数字都要在 facts 中有出处 |
| 人名 | 至少 2 个具名的人 |
| 专名 | **专名内部不许加粗** |

**入库时速查表必须按英文加粗顺序建，不能按中文括注顺序。**
中英语序天然不同（`a **physician** who lived **nearby**` ↔ `住在**附近**的**内科医生**`），
按位置配对会整体串位。这条我在第21篇入库时又犯了一次，被 GLO-02 当场抓住。

## 五、写作时的十一条纪律

**这十一条对应精修的十一轮。动笔时守住，后面就不用返工。**

### 结构（对应轮次 2、3、4）

**1. 不要写会「来得太早」的句子。**
每写一句问：它的回报在哪？如果回报在两段之后，它现在就是横插进来的。
*第02篇*：「船上没有生物学家」原在 §1，夹在两句 ANGUS 之间，谁也接不上；
移到 §3 作为「所以没人说得出这些动物吃什么」的原因才对。

**2. 段落末句要把东西交出去。**
写完一段，读它的末句和下一段的首句：后者接得住吗？
*第21篇*：§4 末交出「左舷结构更多」，§5 首原本直接跳到四把尺——
补一句 `Why more?`，尺才成了被要求的答案。

**3. 连接词必须真的成立。**
写下 so / therefore / 所以 之前，确认前一句真的推得出后一句。
*第13篇*：「基因从没动过；**所以**每一块色斑都是一只钟」——推不出来。

**4. 抽象等事实说尽再出现。** 一般命题只放 §5。

**5. 末段两句格言不能相邻。**
**解法不是插一句无关事实**（曾在五篇制造五处新毛病），
而是合并成一句，并让后半带上具体指涉。
*第21篇范本*：`Every man cut accurately by the scale in his hand and not one was
mistaken; across that hull, no two held the same foot.`
——`across that hull` 把抽象命题钉回了那条船。

### 中文（对应轮次 5）

**6. 不要为对上英文而挤出单字。**
*错*：就**溶**在群落周围 → *对*：**溶解**在群落周围的水里

**7. 一个中文词不能拆成两个英文名额。**
*错*：不**追**(posthumously)**授**(awarded) → *对*：这项**荣誉**从不**追授**

**8. 中英语序不同是正常的**，不要为对齐而扭曲中文。

### 英文（对应轮次 7、11）

**9. 主语用人和具体物，不用抽象名词。**
*错*：Rutherford's **analysis** required… → *对*：**Rutherford** showed…

**10. 被动可以用，但施事要是真能做这件事的东西。**
`The circular was signed by Pickering` 好——它突出署名者不是她。
*第21篇的错*：为消无施事被动写出 `The harbour had shown the fault`——
**码头不会「演示」毛病**，比喻不落地。改为反身：`The fault had shown itself in harbour.`

**11. ★ 同一实体的代词全篇一致。**
*第21篇的错*：船全篇用 `she / her`，唯独一处宾语写成 `finished it`。

### 压词数时的额外一条

**★ 每次为压词数而缩写，回头检查代词和指示词还有没有落点。**
*第21篇的错*：`an archaeologist at the Vasa Museum` 压成 `an archaeologist there`——
**博物馆全篇从未出现过，`there` 没有先行词**，读者会卡在「哪儿的考古学家」。


### 编辑纪律（本项目救命六次）

**改任何一处之前，先把真实文本读出来，再做替换，并用 assert 校验。**
不要凭记忆构造匹配串——曾按记忆猜中文原文，一次同时改坏三篇。

### 指标改动要同步三处

1. `data/*.js` 的 metrics
2. `scripts/final-version-guard.js` 里 README / 交接文档的行校验
3. `.github/workflows/validate-content.yml` 里的硬编码期望值 ← **本地跑不到**

## 八、什么时候算写完

**临界点：改一处若要牺牲另一处（论证、中文、词价、史实、指标），就停手。**

不是「合规分100」就完。**到位的标准是：再动就要拿走一样别的东西。**

判定方法：列出所有「没改」项，逐条回答「改它要牺牲什么」。
**只要还有一项答不上来，就说明还没到。**
