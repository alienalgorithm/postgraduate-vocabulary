## 三、跑轮 · 每一轮的固定四步

### 步骤 A · 开工前先答四句（**动手前，不是交差后**）

① **这一轮我要把哪一处推得更好？**（答不出＝还没开始想）
② **这一处若用尽全力，能到什么样子？**
③ **我现在这一版，离那个样子差多少？**
④ **推完之后，哪一处因此更立得住？**

> **台账三次写成套话，根子就在它是跑完才补的。**

### 步骤 B · 跑机器，把它报的位置逐条走判据

```bash
python3 scripts/inspector.py NN        # 十五层＋PRO-01＋PHR＋DEN-01
python3 scripts/polish.py NN round R   # 本轮的判据与示例
```

**机器只指位置，不下结论。** 每条都要给裁语——**不许群裁**。

### 步骤 C · 改完当场回扫（**七次自伤，五次本可拦下**）

```bash
python3 scripts/rescan.py NN
```

扫五样：新代词的先行词／**主语有没有被新信息挤掉**／同物两名／
句内同词两义／**新称呼前文有没有铺垫**。

### 步骤 D · 记账，功率计当场判分

```bash
python3 scripts/polish.py NN done R --note "…"
```

**满分 12、下限 6，不足即拒收。** 七项：
有真产出3／指名道姓2／有否决2／开工四问2／给对照1／给理由1／走判据1

**低于 9 会提示「尚可推得更满」——那就是没跑到最大功率。**

### 第6轮第七查 · 升格（把文章推到最上乘的那一步）

**前六查只管「这个词配不配占名额」；第七查问「有没有更值的东西能占它」。**

**考研真考的东西里有一大块是动词短语与固定搭配**——逐词都认得、合起来不认得，正是失分处。
库：`data/reference/phrase-wordlist.txt`（88 条）

```
a doubt about it         → cast doubt on it
the change caused a rise → the change gave rise to a rise
they disagreed with him  → they were at odds with him
after the storm          → in the wake of the storm
became persuasive        → carried weight          ← 第16篇实例
```

**两条硬前提**：①**文章必须因此更好**，读着别扭就宁可不换；②必须是真短语（PHR-01 会拦）
**一条下限**：判「本篇无处可升格」是正当结论，**须写明查了哪几处、为什么都不合适**

### 第12轮减法轮 · 每一刀问三句

> 第33篇一轮落五刀、**三刀削坏**

**① 指代还有落点吗？② 语法还完整吗？③ 这个数还是原来那个数吗？**
**答不上任何一句，那一刀就不许落。**

### 第13轮极限轮

**不读台账里的任何理由，只打开正文冷读。**

**两条实测规律**：隔一次会话跑最准／**本轮的改动同样要过冷读**
**一条下限**：第16、25 篇零翻案，理由逐条写进台账。**查过没有就是没有。**

## 六、七条不许碰的红线

1. **不为词数而伤史实**（第14篇差点删掉 `almost three degrees` 的 almost）
2. **改了英文必须回读中文，且中文写完反过来校英文**——**「英文错中文对」已出现 12 次**
3. **标题实词必须在正文有落点，且与收束句所指一致**（第23篇标题与末句所指不一致）
4. **绝不整表重建速查表**——表存词根、正文用屈折形式，**已栽六次**
5. **改动与校验分开跑**——断言失败会让整批编辑不落盘
6. **重建速查表必须带断言**：
   ```python
   assert any('\u4e00' <= c <= '\u9fff' for c in z), (aid, k, z)
   ```
   **没有它，`or w` 的 fallback 会把英文词写进中文栏且不报错。**
7. **改完必跑 rescan**——**改动本身就是新的风险源，已由七次实例证实**

## 七、★★★ 进化 · 这一节不交，这一轮就白跑了

> **本节是整份令的核心。前六节让一篇文章变好，只有本节让项目变好。**

跑完全部十三轮之后，**必须回答这五问**：

### ① 这一轮抓到的问题，属于哪一族？

现有五族：**指代／短语升格／信息密度／功率／改动自伤**

- **若属已有族** → 记「第几次犯」。**同一族犯到第三次，就该问：这条规则为什么拦不住它？**
- **若不属任何族** → **就是新族的种子，走 ②**

### ② 这个坑，机器现在能不能查出来？

- **能** → 它为什么没报？是阈值不对，还是根本没跑到那一步？
- **不能** → **它该变成哪条新规则？** 写出规则名、判据、拦在哪一步

### ③ 立新规则之前，先量

**不许拍脑袋定阈值。** 加 DEN-01 之前量了四个判据，**三个被数据否掉**：
数硬事实（零事实的句子全是好句）／数新实词（中位数 100%）／空评价句（全库 0 句）。
**只有第四个量出了真东西。**

```bash
# 量的模板：把候选判据在全库跑一遍，看它逮出的前十条是不是真问题
python3 -c "…遍历全库…按候选判据打分…打印最差的十条…"
```

**若逮出的前十条里多数是好句子 → 这个判据是错的，换一个。**

### ④ 新规则必须同时做三件事，缺一不算立住

1. **装进检察官或跑轮**（能自动跑）
2. **挂到某条铁律下**（`charter-map.json`）——**没挂铁律 = 不知道它在执行什么**
3. **加回归测试**（正例报出／反例不误报／已挂铁律）

> **实例**：装 PRO-01 时回归测试当场逮住我没挂铁律。**那些测试的用处，自己演示了一遍。**

### ⑤ 报出这一轮的进化账

```
本轮抓到 N 处
  已有族 X 处（哪一族、各是第几次犯）
  新族   Y 处（是什么、量了什么、立了哪条规则）
规则数：从 A 条 → B 条
回归测试：从 C 条 → D 条
```

**若 Y=0 且已有族没有犯到第三次 → 明写「本轮无新规则可立，理由是…」。**
**这也是正当结论——但不许略过不答。**
