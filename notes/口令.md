# 口令

用户只说这三个词，其余全部由我执行，不要求用户看任何文档。

| 口令 | 我必须依次做完的事 |
|---|---|
| **写NN** | 重读三篇范文 → 按四条标准选题并核实事实 → `agent brief` 取词池 → 起草并 `agent review` 迭代至阻塞项为0 → 入库（速查表按英文加粗顺序建）→ `build_markdown` + `inspector` → `polish` 十一轮逐轮跑 → 临界点审计至全否决 → 存快照 → 同步指标三处 → `preflight` → 推送并等CI → `export_one` 出单篇文件 |
| **修NN** | 存快照 → `polish NN` 十一轮逐轮跑（每轮记台账）→ 第八轮回退审计 → 第九轮冷读 → 临界点审计（至少五条提案，全被代价否决才算到）→ `inspector` 确认含REG层无回退 → 同步三处 → `preflight` → 推送 → 出单篇文件 |
| **查** | `inspector` 全库排名 + `preflight`，报告哪篇最该动 |

**不存在预设词表。** 写作流程是：选题 → 写研究笔记 → 用 `agent brief`
从笔记里挑出未被前面用过的词 → 写文章 → 落 50 个加粗。
唯一的词汇约束是跨篇不重复（含同根）。**不要汇报「剩余多少词」这类数字**——
没有那个池子。

规矩：
- 篇号缺失就问一句，不要自己猜
- 全程不要求用户看手册、不要求用户跑命令
- 每一步的结论用一两句话讲清「改了什么、为什么」，不列命令输出
- 交付时给单篇文件，不要让用户在全库文件里翻
