## 轮次记录

### 第1轮 · 已完成 · 机器层

改了：无。
没改：三条提示全部保留。
理由：GLO-03 报 anatomist 非原形——它就是词典原形（解剖学家），非屈折形式。
ZH-01 报 §5「**像**(resembled)」——「这些骨头像什么」是自然中文，像在此处能独立成词。
ZH-01 报 §5「**躺**(lain)」——「各自躺了多久」是本词，且与 §4「躺得越久，存得越多」形成呼应，是全篇氟测年逻辑的关键动词，不可换。
合规分 100，硬伤 0，preflight 全绿。

### 第2轮 · 已完成 · 句序层

改了：无。
没改：两个 ⚠ 均保留。
理由：§1句1 是布景句，交代谁在何时把什么摆到哪里；回报在 §4（这堆骨头被重新检验）是全篇设计——不先摆出骨头，后面无从检验。它与句2共享 jaw/skull，实际接得上，词面统计未识别出屈折与同义。
§1句3「made it English」回报在 §3 的 acclaim（追捧），中间隔着 §2 的质疑——这个延迟是有意的：先给民族自豪，再给质疑，最后说明追捧与异见取用同一副骨头。若把它挪到 §3 附近，§1 就失去了「英国有了自己的先祖」这个情绪落点，而 §2 的质疑也就没有了反衬对象。
其余「前后皆不接」是词面统计的假象：§2 是时间链（1913→1915→1923→被无视三十年），§4 是推理链（施用测法→原理→读数→结论），靠概念承接而非词面重合。

### 第3轮 · 已完成 · 接缝层

改了：无。四处接缝全部成立。
§1→§2「英国有了自己的先祖」→「疑问当即就来了」：民族自豪接到质疑，最强的一处对撞。
§2→§3「他是对的，也被无视了整整一代人」→「解剖学判不了这件事」：前句留下的问题（为何对的人被无视）正由后句回答。
§3→§4「这场争论没有裁决者」→「1949年奥克利施用了氟测年法」：裁决者到场。这是全篇的枢纽接缝。
§4→§5「没有在同一片土里待过同样长的时间」→「更进一步」：氟测年证明不是同一个体，锉痕再证明是人为，层层递进。
没改的理由：共享实词一列全为空，但四处都靠概念承接——按材料提示不据此判断。

### 第4轮 · 已完成 · 因果层

改了：§5倒数第二句 local stone → Piltdown stone。
没改：①§3 的 so；②无抽象前置。
理由：① so 成立——关节断掉，所以两块永远拼不到一起去验，这是真因果，不是第13篇那种「基因没动所以是钟」的伪推导。
② 本篇一般性命题只在末句出现，前四段全是事实与推理，无抽象前置。
③ 末两句被判都是纯议论。按规则不插无关事实，改为让倒数第二句带上具体指涉：染色配的是皮尔当当地的石头。地名把造假这个动作钉回具体地点，同时消除相邻。
另核：末句 Those experts had asked what the bones resembled; the test asked how long each had lain — and only that question had a number 已含 test 这一具体所指，不是悬空命题。

### 第5轮 · 已完成 · 中文层

改了：无。
没改：十二处单字加粗全部保留，无疑似拆词。
理由：逐条读过，每一处都在自身搭配里成立——摆到…面前、砾石坑、颌骨像猿、配上一颗人的头骨、那些牙、被磨过的、拼不到一起、去验、氟测年法、埋在地里、躺得越久、存得越多。这些不是为对英文而挤出的碎片，而是中文里本就这么说。
特别核过两处：§2「被**磨**(abraded)过的」——磨牙、磨损都是本词；§4「**躺**(lies)得越久，**存**(holds)得越多」——这两个单字构成对仗，且与 §5「各自躺了多久」呼应，是氟测年逻辑的关键动词。
另核：无一处中文词被拆成两个英文名额（入库时 ZH-02 曾抓到「锉痕」被拆成 file+marks，已改为 file grooves 对应「锉出的沟槽」）。
中英语序有多处相反（如「摆到伦敦地质学会面前」对 laid before the Geological Society），属正常，未为对齐而扭曲。

### 第6轮 · 已完成 · 词价层

改了：link → transitional。
没改：generation(4.82)、file(4.75)、images(4.75)、lies(4.73)、applied(4.67)、holds(4.60) 六个边缘词保留。
理由：generation 在「被无视了整整一代人」中是时间尺度的本词，换 era/epoch 会失去「一代学者」这层人的意味。
file 在 §5 是 file grooves（锉出的沟槽），是造假手法的本词，不可换。
images 指 X 光片，plates 已被第08篇占用，photographs 不合当时语境。
lies 与 holds 在 §4 构成「躺得越久，存得越多」的对仗，是氟测年原理的两个关键动词，换任一个都会破坏这组对照。
applied 指施用一种测法，是实验室本词。
换词前已用 agent 四通道冲突检测查过 transitional，跨篇含同根无冲突。

### 第7轮 · 已完成 · 母语者层

改了：无。
没改：两处无施事被动、句长分布、抽象主语三项均不动。
理由：两处被动是本篇的题眼，不能给施事——
  §2「whose teeth had been abraded」：谁磨的？这正是全篇要问而当时无人能答的。若写成 someone had abraded them，就把「不知是谁」这个事实说漏了。
  §3「the hinge where jaw met skull was broken away」：关节是谁弄断的？1953年才知道是造假者刻意去掉，1912年没人知道。被动在此保留了当时的认知状态。
  参照语料被动率 22.4%，本篇 2/19 约 10.5%，本就低于母语标准，无需再降。
句长实测 27→12→10→4→4→26→18→8→24→16→14→8→15→14→11→10→14→15→23，长短交替充分，无三个短句连排；均长约15是270词上限与50重点词双重约束的必然结果。
抽象名词作主语：零。全篇主语均为人或具体物（Dawson、skull、Waterston、Weidenreich、Anatomy作为学科可视为具体做法、bone、pieces、molars、experts）。

### 第8轮 · 已完成 · 回退审计

两处改动全部保留，零回退。
遮住理由并排重读的结论：
【第4轮 local stone → Piltdown stone】保留。单看两版也选新版——「配上当地石头的颜色」是泛指，「配上皮尔当当地石头的颜色」把造假这个动作钉在了那个具体的砾石坑上，而那正是全篇开头道森取材的地方，首尾因此扣合。
【第6轮 missing link → transitional form】保留。missing link 是被用滥的套语，读者会滑过去；transitional form 是古人类学的本词，说的是「介于两者之间的形态」这个具体主张——正因为它是一个可被证伪的主张，后面推翻它才有分量。且词价 4.99→3.64，考生学到的东西更多。
三条自毁模式复查：
1 为消告警而牺牲文章——无。第4轮的格言相邻用「加具体专名」解决，未插一句无关事实。
2 为满足指标而伤中文——无。两处改完均重读中文，「那个过渡型」「皮尔当当地石头」自身成句。
3 改动扩散到别篇——无。全库回跑 22 篇硬伤 0，平均 97.7，其余 21 篇指标未动。

### 第9轮 · 已完成 · 整体冷读

冷读三问：
① 读到哪里卡了一下——§5末句 Those experts。「那些专家」指谁？§3 争论的双方，还是 §2 被无视的怀疑者？指代含混，而且带轻蔑色彩，与全篇克制的语调不合。已改为 For forty-one years the inquiry was…——不指人，只指那个被反复追问的东西，同时补上四十一年这个跨度，与 §1 的1912、§5 的1953 首尾扣合。
② 哪一句想停下来再读一遍——the argument had no arbiter。这是全篇的枢纽：不是证据不够，是没有能做出判决的东西。
③ 明天还会记得哪一句——0.03% 与 0.1%。两个数字并排，胜过任何形容词。
整体读感：五段是一条线——英国得到先祖→质疑当即出现却被无视三十年→解剖学为何判不了→氟含量做出判决→锉痕证明是人为。反转成立（怀疑者一直是对的，改变结局的不是更好的论证，是换了一个有数字作答的问题）。
按规程冷读改动后重跑第八轮：本处遮住理由并排读仍选新版（Those experts 是含混的人称，the inquiry 是精确的对象），保留。全库回跑 22 篇硬伤 0，无扩散。

### 第11轮 · 已完成 · 地道性专读

改了：§4句3 held→carried 并补上 fluoride 这个单位。
没改：其余四项全部通过。
逐项结论：
① 冠词——齐。入库时已修一处 with orangutan mandible → with an orangutan mandible。复查 a jaw、a gravel pit、a human skull、an ape jawbone、a fluorine test、a generation、a number 均正确。
② 代词一致——本篇无需用性别代词的实体（第21篇的船用 she/her，本篇的对象是骨头，用 the pieces/each 即可），无不一致。
③ 先行词——每个指示词都有落点：§3「settle it」的 it 指前句争论、「what it expected」的 it 指 each side、§5「only that had a number」的 that 指前半句那个测试问的问题。无悬空。
④ 搭配——逐句读过。laid before the Geological Society、doubt came at once、echoed him、read the same plaster casts、drew on one set of bones、the argument had no arbiter、absorbs fluoride from groundwater、chewing leaves uneven wear、proved the dark colour skin-deep，均为自然英语。
⑤ 比喻落地——两处需查：Dissent and acclaim drew on one set of bones（异见与追捧「取用」骨头，抽象名词作施动但 draw on 本就可搭配抽象主语，成立）；the argument had no arbiter（争论「没有裁决者」，arbiter 本义即裁断人或裁断依据，成立）。均非第21篇 The harbour had shown the fault 那种不落地的拟人。
改的一处理由：held 在前一句已用作 the more it holds，同词紧邻重复；且 per cent 后缺单位，母语读者会问「百分之零点零三的什么」。
