## 一、英文词法 / 句法（EN）

| 编号 | 状态 | 缺陷 | 实例 | 修正 |
|---|---|---|---|---|
| EN-01 | ✅ | 词义误替 | `fell **abruptly**`（abrupt=突然，非"陡"） | `fell steeply` |
| EN-02 | ✅ | 搭配拆断 | `superior **retention** to`（superior…to 被名词劈开） | `produced better X than` |
| EN-03 | ✅ | 搭配错配 | `ambitious instrument`（ambitious 不修饰器物） | `a powerful instrument` |
| EN-04 | ✅ | 搭配错配 | `resembles knowledge`（resemble 说客观相似，此处该说感受） | `feels like knowledge` |
| EN-05 | ✅ | 搭配错配 | `waste is not trivial` | `The cost is not trivial` |
| EN-06 | ✅ | 搭配错配 | `the lesson emerged` | `took time to sink in` |
| EN-07 | ✅ | 搭配错配 | `compressed into one night` | `crammed into one night` |
| EN-08 | ✅ | 同义反复 | `slowed to a gradual decline`（slowed=gradual） | `settled into a gradual decline` |
| EN-09 | ✅ | 范畴打转 | `fell… then slowed to a decline`（下降后减速成下降） | 给数字：`Half was gone within the hour` |
| EN-10 | ✅ | 悬空动名词 | `the cost of keeping`（无宾语） | `keeping anything at all` |
| EN-11 | ✅ | 比较不对等 | `than when compressed`（省略主语断裂） | 把比较项写全 |
| EN-12 | ✅ | 语序错位 | `are systematically the most misled` | `the harder…the more…` |
| EN-13 | ✅ | 绝对化夸张 | `demands nothing / leaves nothing behind` | `demands far less` |
| EN-14 | ✅ | 补丁泄气 | `much of what learning consists of` | 加限定词而非加"大部分" |
| EN-15 | ✅ | 裸时间短语 | `tested himself an hour later`（缺 after/again） | `tested himself again after an hour` |
| EN-16 | ✅ | 定冠词预设 | `the trace`（未引入就用定冠词） | `the memory` |
| EN-17 | ✅ | 一词多义风险 | `architecture`（非建筑义读者反应不过来） | `structure` |
| EN-18 | ✅ | 一词多义风险 | `prices what we keep`（price 作动词造引申义） | `shows the cost of…` |
| EN-19 | ✅ | 冗余对 | `return back / repeat again` | 删一个 |
| EN-20 | ✅ | 首尾撞词 | 两次 `set out to` | 后一个改 `meant to` |
| EN-21 | ⬜ | 及物性 | `Shut the book and **retrieve**`（retrieve 缺宾语） | 补宾语 |
| EN-22 | ⬜ | 指代链断裂 | `Half was gone`（Half of what？砍词砍掉了先行词） | 保留先行词 |
| EN-23 | ⬜ | 同一代词两义 | `It took another 120 years to learn what to do about it`（两个 it 指代不同） | 拆句或换名词 |
| EN-24 | ⬜ | 自作聪明的双关 | `instruction` 隔三行两义（指令/教学），读者只会读成重复 | 换词 |
| EN-25 | ⬜ | 连接词撞车 | `accordingly` 与 `therefore` 背靠背 | 删一个 |
| EN-26 | ⬜ | 关键词提前用掉 | `effort` 在第三段用了，末段"the price is effort"就成了重复 | 为末句留词 |
| EN-27 | ⬜ | 搭配生造 | `a cause a man could **reach**`（reach 不接"原因"） | 换动词 |
| EN-28 | ⬜ | 内容错误 | `chosen because they meant nothing`（把方法论说成怪癖；实为排除已有联想干扰） | 查原始文献 |
| EN-29 | ⬜ | 说过头 | `The mechanism is well understood`（与"2008年才有决定性答案"打架） | 降调 |
| EN-30 | ⬜ | 编造史实 | `the board still believed in bad air`（无据；实为"未接受解释，只接受建议"） | 核查后再写 |

## 二、中文译法（CN）

| 编号 | 状态 | 缺陷 | 实例 | 修正 |
|---|---|---|---|---|
| CN-01 | ✅ | 造词 | "回忆量"（中文无此词，把 recall 当名词硬译） | 换人做主语 |
| CN-02 | ✅ | 翻译腔 | "留存效果好于" | "记得更牢" |
| CN-03 | ✅ | 改事实 | "曲线转平"（原文一直在降，只是慢了） | "慢慢淡去" |
| CN-04 | ✅ | 虚指做实 | "每一个十年都有人验证"（every decade 是虚指） | "一百多年来反复验证" |
| CN-05 | ✅ | 翻译腔 | "对…进行了 / 具有…性 / 起到了…作用" | 用动词直说 |
| CN-06 | ✅ | 抽象主语 | "记得住的内容急剧减少"（英语可 Recall fell，中文不行） | "最初几个小时就丢了一半" |
| CN-07 | ✅ | 程度越界 | "忘得**最快**"（英文 steeply 无最高级） | 去掉程度词 |
| CN-08 | ✅ | 语域降级 | mastery 译成"吃透了"（社论体里冒出口语） | "已然掌握的错觉" |
| CN-09 | ✅ | 添加意象 | unmeasurable 译成"斥为**空谈**"（空谈是加的） | 逐字核对 |
| CN-10 | ⬜ | 漏限定词 | 漏掉 effective，"学习大部分由困难构成"变成假话 | 限定词必须译出 |
| CN-11 | ⬜ | 用引申义代替本义 | blame→"算在头上"、draw→"打水"、fits→"说得通" | 用词典本义：归咎于 / 汲取 / 吻合 |

### 中文译文的总病根

**为了让加粗词对齐英文，把中文句法也照着英文搭。**

**解法**：中文按最自然的说法写 → 加粗落在那个自然说法上 → 后面用 `(english)` 括注词源。

## 三、篇章与事实（ST）

| 编号 | 状态 | 检查项 | 踩过的坑 |
|---|---|---|---|
| ST-01 | ✅ | 论证次序 | 机制段放在实验段之前 → `evidence` 指代链断裂 |
| ST-02 | ✅ | 年份自洽 | 写 `a century` 但文中跨度 1885→2008 = 123 年，自相矛盾 |
| ST-03 | ✅ | 段落节奏 | 五段等长 → 读起来平板；应让一段明显短 |
| ST-04 | ✅ | 可执行动作 | 全文无一句祈使句，读者不知该怎么做 |
| ST-05 | ✅ | 格言拥挤 | 同段连着两句警句，互相削弱 |
| ST-06 | ✅ | 限定词守恒 | merely / arguably / effective 在中文里丢失 |
| ST-07 | ⬜ | 论点无证据 | 第二段讲"分散学习"，第三段实验却是"提取练习"——两个不同现象 |
| ST-08 | ⬜ | 修改引入回归缺陷 | 约 1/3 的新缺陷是上一轮改动造成的 |
| ST-09 | ⬜ | 地点未定位 | `Soho` 未说明国家/城市（伦敦和纽约都有 Soho） |
| ST-10 | ⬜ | 数字前后不一 | 首段 500、末段 500、中间 535，读者混淆；史实为 616 |

## 四、密度红线

| 密度 | 判断 | 实测后果 |
|---|---|---|
| ≤18% | 安全 | 可以优先选最地道的词 |
| 18–22% | 紧张 | 偶尔被迫在"最准的词"与"名单上的词"之间选后者 |
| >22% | 危险 | **句子被系统性压坏**，绝大多数英文缺陷产于此区间 |

**200 词 + 50 词 = 25% 曾两次导致文章不可读。**
若要求更短，必须同时降关键词数，不能只压词数。
