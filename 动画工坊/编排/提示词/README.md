# 提示词

这里是做动画每一步的提示词。`../新片.workflow.js` 和 `../改片.workflow.js` 只给代理传变量，让它读这里的文件照做，所以这里是唯一的正本：改提示词只改这里，模板不用动。

不用工作流时，也可以直接用：开一个新会话，把某个文件的内容整段发过去，把 `{变量}` 换成实际值。

| 步骤 | 文件 | 主要变量 |
|---|---|---|
| 立项 | 立项.md | 片名、英文短名、作品目录、工作目录、模板作品、主题、风格、片长范围、配乐模式 |
| 证据 | 证据.md | 作品目录、主题 |
| 音乐分析（search 模式先选曲） | 音乐分析.md | 作品目录、工作目录、配乐模式、配乐文件 |
| 内容草稿（每个角度一份） | 内容草稿.md | 角度名、角度、片长范围 |
| 内容计划（定论点、结构、片长） | 内容计划.md | 作品目录、工作目录、片长范围 |
| 音乐剪辑 | 音乐剪辑.md | 作品目录、工作目录、原曲 |
| 音乐质检（通过后入库） | 音乐质检.md | 作品目录、工作目录、原曲、配乐模式、密钥文件 |
| 分镜 | 分镜.md | 作品目录 |
| 事实核查 | 事实核查.md | 作品目录、署名 |
| 场景构建 | 场景构建.md | 场景、开始、时长、概要、复用、本机配乐 |
| 场景审查 | 场景审查.md | 场景、开始、时长、构建说明 |
| 导演打磨 | 导演打磨.md | 作品目录 |
| 场景修改（导演意见、改片共用） | 场景修改.md | 场景、问题、改法 |
| 备用配乐 | 备用配乐.md | 作品目录、工作目录、备用曲 |
| 最终质检（画面、声音各一份） | 最终质检.md | 方面、本机配乐 |
| 出片（推送，GitHub 出 4K） | 出片.md | 片名、英文短名、分支、配乐、发布、段数、检查片段、封面、本机配乐 |

变量的意思：
- 作品目录：仓库里的 `动画工坊/作品/<片名>`，进仓库（代码、分镜、小文件、加密配乐）。
- 工作目录：仓库外的临时目录，放有版权限制的音频明文和大中间文件，不进仓库。
- 配乐模式：licensed（用户给的已授权曲子，入库时加密）、cc0（给定 CC0 曲子）、search（从免版权网站选曲）。
- 配乐（出片用）：main、backup、none，和 `动画工坊/渲染请求.json` 的 music 字段一样。
- 本机配乐：本机出 1080p 检查片段时混进去的配乐文件，一般是 `{工作目录}/music/score.wav`；不存在时提示词会让代理先用 decrypt_music.sh 解出来。

所有提示词共同的规矩（写在每部片的 BRIEF.md 里，提示词第一句都让代理先读它）：检查只查片子本身（声音、文字、画面）；只有质量问题能卡住流程；受限音频明文不进仓库；文档不用破折号和加粗。
