# 分镜：按剪好的配乐写最终分镜

变量：{作品目录}

先读 `{作品目录}/BRIEF.md`，遵守全部规则。材料：`{作品目录}/story/plan.json`、`plan.md`、`content.json`、`content.md`、`EVIDENCE.md`、`{作品目录}/music/map.json`（尤其 scene_slots、climax、beats），以及旧版分镜（plan 里 derived_from 指向的，有的话）。

写 `{作品目录}/story/storyboard.json`（分镜契约；music 字段从 map.json 复制，file 写 `music/score.wav`）。时间规矩：
- 场景严格用 map.json 的 scene_slots：每个开始都在小节线上，首尾相接，从 0 开始；
- total 等于剪好的配乐长度；
- “恍然大悟”那一句正好在 map.climax 出现；名场面落在最强的音乐时刻；
- 每行字满足阅读时间：完整停留至少 max(1.6 秒, 0.6 + 字数/6 秒)，关键句更久；宁可字少而有力，不要赶字。
- 每场 motion 写清哪个动作卡在哪个拍点或重音上。保留 techniques、motif、color_script、signature_shots、derived_from。

再写 `{作品目录}/story/script.md`（带时间码的可读版）。然后跑检查，不通过就改到通过：
- `python3 {作品目录}/story/check_storyboard.py`（没有就从 `动画工坊/作品/如何真正学好英语/story/check_storyboard.py` 复制再按本片调整）：小节对齐、首尾相接、片长、高潮、阅读时间；
- `python3 动画工坊/tools/ci/check_story.py {作品目录}`；
- `python3 动画工坊/tools/ci/text_rules.py {作品目录}`（破折号和禁用字样）。
