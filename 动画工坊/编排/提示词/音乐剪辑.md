# 音乐剪辑：按内容计划剪配乐

变量：{作品目录} {工作目录} {原曲}

先读 `{作品目录}/BRIEF.md`，遵守全部规则。再读 `{作品目录}/story/plan.json` 和 `plan.md`（每场目标时长、能量、音乐角色、“恍然大悟”的位置）、`{工作目录}/music/analysis.md` 和 `src_map.json`、`动画工坊/tools/music/README.md`（方法、edit_plan.json 格式、踩过的坑）。原曲是 {原曲}。

目标：配乐的起伏跟着内容走。开头是安静的固定音型，揭示一个个出来时声部一层层进入，然后推进，全片最满的高潮正好落在“恍然大悟”那一句，方法卡和署名下面是温暖干净的收尾。为了凑到计划的片长，可以截段、整乐句循环、重复段落；只有明显更好而且调性、速度、音色和谐时才混 CC0 曲子，否则只用原曲。

规矩：
- 只在真实小节线剪，等功率交叉淡化（按两边相关系数修正增益），接缝听不出，听起来像原本就是这么写的；出点和入点前后和弦一致，接口尽量放在换和弦处；
- 不改音高；变速只在不得已时用，且不超过 3%；
- 高潮只经过一次，放在最后一次经过；
- 安静段落可以用宏观增益整体抬高（余弦缓变，没有阶跃），手机外放也要听得见；
- 结尾自然收住，除非故意落在最后一个重音上。

用程序剪（虹吸，不要临时手写渲染代码）：
1. 写 `{工作目录}/music/edit_plan.json`：grid 用 src_map.json 的 bars，edit 写段落、接口淡化、淡入淡出、宏观增益，master 用默认（-14 LUFS，限幅上限 -1.2 dBTP）。格式照 `动画工坊/作品/如何真正学好英语/music/edit_plan.json`。
2. `python3 动画工坊/tools/music/rebuild_score.py --source {原曲} --plan {工作目录}/music/edit_plan.json --out {工作目录}/music/score.wav --info {工作目录}/music/edit_info.json`
3. `python3 动画工坊/tools/music/check_score.py {工作目录}/music/score.wav --ref {原曲}`，不通过就改方案重来。
4. 每个接缝再做数值检查（采样跳变、RMS 和频谱连续、相位），截接缝前后的频谱图 Read。
5. 把计划的场景边界吸附到剪好的配乐的小节线上，场景时长可以小动，保证乐句完整。
6. 定稿后：
   - `python3 动画工坊/tools/music/make_edit_plan.py --map {工作目录}/music/src_map.json --edit <只含 edit 部分的 json> --score {工作目录}/music/score.wav --out {工作目录}/music/edit_plan.json` 写出带核对信息的最终方案；
   - 对成品跑 `analyze_track.py {工作目录}/music/score.wav --out {工作目录}/music/final --png`，把 energy.json 复制成 `{工作目录}/music/energy.json`；
   - 写 `{工作目录}/music/map.json`（剪好的配乐自己的时间轴：bpm、beat_offset、bar、beats、bars、sections、climax、total，加 scene_slots [{id,start,duration}]，都在小节线上），格式照 `动画工坊/作品/如何真正学好英语/music/map.json`；
   - 写 `{工作目录}/music/edit.md`（每个剪点和循环的原曲时间、成品时间、理由）；混了 CC0 曲子就更新 LICENSES.md。

返回 ok、notes（长度、响度、真峰值、接口数、高潮时间）、files。
