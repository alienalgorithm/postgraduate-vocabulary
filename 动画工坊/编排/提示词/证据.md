# 证据：查研究，写 EVIDENCE.md

变量：{作品目录} {主题}

先读 `{作品目录}/BRIEF.md`，遵守全部规则。

1. 为 {主题} 找有研究支撑的结论 8 到 15 条。优先综述、元分析、经典实验；只用查得到原文或权威摘要的，查不到就不写。
2. 每条写：
   - 一句可以直接上屏的中文（短、准，不夸大）；
   - 角落小字出处，例如 “Ebbinghaus, 1885”；
   - 完整出处：作者、年份、标题、期刊或出版社、卷期页；
   - 它能说明什么，不能说明什么；
   - 允许上屏的数字和确切写法（没有就写“不上数字”）；
   - 可信度（高、中、低）和理由。
3. 不编数据；不写“保证学会”“X 天流利”之类承诺；不贬低任何人。
4. 写 `{作品目录}/story/EVIDENCE.md`，编号 F1、F2……

返回 ok、notes（条数，最有说服力的 3 条）、files。
