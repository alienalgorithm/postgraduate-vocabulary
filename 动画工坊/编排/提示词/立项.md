# 立项：建作品目录，写本片规矩 BRIEF.md

变量：{片名} {英文短名} {作品目录} {工作目录} {模板作品} {主题} {风格} {片长范围} {配乐模式} {配乐文件} {配乐说明} {备用配乐} {署名}

1. {作品目录} 不存在就运行 `TEMPLATE={模板作品} bash 动画工坊/tools/new_film.sh {片名} {英文短名}`（复制引擎、字体、依赖清单，放两场能出图的小样）。已存在就跳过这一步，不覆盖任何文件。
2. 在 {作品目录} 里 `npm ci`；本机没有 Chromium 就按 package.json 里 playwright 的版本装；字体按 `动画工坊/tools/fonts.md` 装好。用 `node {作品目录}/engine/still.js --scale 1 1` 出一张图并 Read，确认能用。
3. 建工作目录 {工作目录}（不在仓库里）：`music/user/`、`music/work/`、`tmp/`。配乐模式是 licensed 时把 {配乐文件} 复制到 `{工作目录}/music/user/`。有版权限制的音频明文只放工作目录，绝不放进作品目录（仓库是公开的）。
4. 以 `{模板作品}/BRIEF.md` 为底本写 `{作品目录}/BRIEF.md`：
   - “用户要求”一节换成本片：主题 {主题}；风格 {风格}；片长 {片长范围} 秒，由内容决定；署名只写 {署名}，不写任何个人身份信息。
   - 沿用：硬性规则、分镜契约、渲染框架契约、经典级标准、全技巧工具箱。工具箱里“用户自有素材”只列本机真实存在的路径。
   - “目录”一节写清作品目录（进仓库：代码、分镜、小文件、加密配乐）和工作目录（不进仓库：配乐明文、大中间文件）各放什么；所有路径换成本片的，不留模板作品或旧工作目录的路径。
   - “配乐”一节按 {配乐模式} 写：
     - licensed：曲名、{配乐说明}（授权说明和 B站 简介署名），备用配乐 {备用配乐}；
     - cc0：{配乐文件} 的来源和许可原文；
     - search：选曲规则。CC0 或公共领域优先；CC-BY 只作备选，并在简介署名；NC、ND、许可不明的一律不用。可访问 freepd.com、opengameart.org、freemusicarchive.org、files.freemusicarchive.org、incompetech.com。
     - 三种模式都写剪辑规矩：片长由内容定；配乐可截段、可循环、可混同速同调的 CC0 曲子；只在小节线剪，等功率交叉淡化，接缝听不出；不改音高，变速不超过 3%；全片最满的一刻放“恍然大悟”；结尾自然收住；48 kHz 立体声 24 bit，-14 LUFS，真峰值不超过 -1 dBTP。
   - 文档里不用破折号，不用加粗。
5. 改 `{作品目录}/film.json`：title 和 release.display_name 用 {片名}；release.tag_prefix 用 `anim-{英文短名}`，asset_basename 用 {英文短名}；配乐模式不是 licensed 时删掉 music.main（出片自动用 music.backup）。

返回 ok、notes、files。
