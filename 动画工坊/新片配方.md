# 新片配方

做一部新片的步骤清单。每一步写清用什么、产出什么、怎么验收，标“GitHub”的在 Actions 上跑。

最省的做法：有 Claude Code 的 Workflow 工具时，直接用 `编排/新片.workflow.js`，它按下面的顺序调代理（参数见 `编排/README.md`，示例在 `编排/示例/`）。没有时，按本页一步步做，每步把 `编排/提示词/` 里对应的那一份发给一个新会话，把 `{变量}` 换成实际值。标准见 方法与理念.md。

两个目录先分清：

- 作品目录 `动画工坊/作品/<片名>`：进仓库，放代码、分镜、小文件、加密配乐。
- 工作目录（仓库外，例如 `/tmp/anim-work/<英文短名>`）：放有版权限制的音频明文和大中间文件，不进仓库。

## 省 token 的开关

- 已有证据：把旧的 EVIDENCE.md 给第 1 步，不再查。
- 已有场景代码：分镜里用 `derived_from` 指向旧场景，构建时改写旧代码。
- 不需要的步骤可以跳过：多角度草稿、GitHub 预览、导演打磨、备用配乐（工作流参数 `skip`）。最少约 10 + 2 x 场景数个代理。
- 中断了用 `resumeFromRunId` 续跑，已完成的代理直接用缓存结果。
- 只改字、改字的时间、重新出片：零代理，见 README.md 路二。

## 新片要注意

- 英文短名只用小写字母、数字、连字符，用于 Release 标签和文件名；片名里不要有空格和斜杠。
- 配乐不是用户授权的曲子时，删掉 film.json 的 `music.main`，出片自动用 `music.backup`（CC0 曲子明文放在 `music/backup/score.flac`）。
- 新加的字体要可再分发，许可证放进 fonts/，在 index.html、design.css 里声明，engine.js 的字体名单 FAMILIES 也要加（见 tools/fonts.md）。
- 画面上的字只能来自作品的 fonts/：写了字体里没有的字，GitHub 上会显示成方块。
- 三个工作流不用改：请求里写新片名，anim-check 自动查 `作品/` 下的每一部。
