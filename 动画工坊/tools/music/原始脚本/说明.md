# 原始脚本

2026-11-19 做《如何真正学好英语》配乐时在工作目录（A = 本片的工作目录）里写的脚本，原样保存作为历史。
里面有工作目录的绝对路径，不能直接跑；能直接用的整理版在上一级（analyze_track.py、rebuild_score.py、check_score.py 等）。

| 目录 | 原位置 | 内容 |
|---|---|---|
| `tools/` | A/music/tools | 选曲：在 freemusicarchive、opengameart 找 CC0 曲子（fma_*、oga_*），下载并记录许可（finalize.py、finalize2.py），批量分析候选曲（analyze.py、bars.py、grid.py、gridcheck.py、spec.py），画剪辑方案对比图（editplan.py） |
| `cw_py/` | A/music/cw/py | 《Cornfield Chase》速度和拍网格：十六分音符相位、拍网格拟合、前奏 |
| `cc_py/` | A/music/cc/py | 《Cornfield Chase》结构分析：特征、低音、和弦、拍号折叠、小节表、循环候选和接缝试渲染（loops.py、seamtest.py）、地图（build_map.py → cc_map.json）、analysis.md 生成（write_md.py）、通用剪辑器 cc_edit.py |
| `cc_plans/` | A/music/cc/plans | 早期的三个示例剪辑方案 R1、R2、R3 |
| `edit2_py/` | A/music/edit2/py | 成片剪辑：lib.py（共用函数）、render.py（小节线剪辑渲染）、master.py（宏观增益、归一、限幅、抖动；master_prev.py 是修限幅器之前的旧版）、seams.py（每个接口的数值检查）、verify.py（整条检查）、specimg.py（接口频谱图）、finalize.py（写 map.json、energy.json）、其余是试验用的小工具 |
| `edit2_json/` | A/music/edit2 | 剪辑规格的演变：p0 → d1 → d2 → d3 → d4 → final.json（成片用 final.json，已并进 作品/如何真正学好英语/music/edit_plan.json） |

备用配乐（CC0《Epic Vista》旧时间轴版本）的剪辑脚本在 作品/如何真正学好英语/music/director/。

整理版和原脚本的关系：scorelib.py 的 render、master、limiter、integrated 与 edit2_py 的 render.py、master.py、lib.py 逐行一致（只把小节表从全局变量改成参数），所以 rebuild_score.py 重建出的 score.wav 和成品逐字节相同。
