# B站封面

选用：反常识警告版，标题“别再反复看单词了”，主体是 abandon（单词书第一页那个词）被划了三遍重点还在化成沙子，副标题“一周后，反而记得更少”（Roediger & Karpicke 2006，片中原句）。

| 文件 | 用途 |
| --- | --- |
| upload_16x9.jpg | 上传 B站用，1920x1080，约 1 MB |
| upload_4x3.jpg | 上传 B站用，1440x1080，约 0.7 MB |
| master_16x9.png | 母版 3840x2160 |
| master_4x3.png | 母版 2880x2160（单独排版，不是裁出来的） |

重建（在本目录）：`node build.js` 出两张母版，`python3 check.py` 出上传版并跑全部程序检查（尺寸、信息流小图标题高度、底部 18% 安全区、对比度、禁用字样）。本仓库里重建和原图逐像素一致。字体用上一级的 fonts/。

做法：四个方向同时做（数字对比、反常识警告、电影海报、悬念提问），每个都出 16:9 和 4:3，只用程序检查，不做 AI 审查；最后由主会话把八张和信息流小图放在一起看，选了点击欲最强的一版。另外三个方向的源文件和上传版在 备选/，是当时的记录（脚本里的路径指向当时的工作目录 A）。
