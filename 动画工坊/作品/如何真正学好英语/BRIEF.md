时间单位是秒；texts 的 in/out 相对场景开头；场景开始时间落在音乐小节线上；scenes 从 0 开始首尾相接，最后一个场景结束于 total。

## 渲染框架契约（engine 必须实现，场景必须遵守）
- A/engine/index.html 载入 GSAP、字体、A/engine/design.css（设计系统：颜色变量、字体类、常用效果），按 storyboard.json 依次挂载 A/scenes/sNN.js。
- 每个场景文件 A/scenes/sNN.js 调用 window.registerScene('sNN', function build(tl, root, ctx){...})：在 root（铺满画面的 div）里建元素，把所有动画加到 tl（一个从 0 开始、长度等于场景时长的 GSAP 子时间线）上；ctx 提供 {duration, width, height, palette, util}。不能用 setTimeout、requestAnimationFrame、CSS animation、Math.random（要随机就用 ctx.util.rand(seed) 这类确定性函数），一切动画都必须能被时间线 seek 到任意时刻并得到同一画面。
- 主时间线 paused；window.seek(t) 跳到全片第 t 秒并保证画面就绪；场景在自己的时间段外不显示。
- A/engine/still.js：node still.js [--scale 1|2] <t1> <t2> ... 输出 A/stills/t_<秒>.png（默认 --scale 1 即 1920×1080，用于快速检查；--scale 2 为 3840×2160，用于检查 4K 细节）。
- A/engine/render.js：node render.js --from <s> --to <s> --out <file.mp4> [--fps 60] [--scale 1|2] [--crf N] [--parallel 4]，逐帧 seek 截图并用管道送进 ffmpeg（libx264 high，yuv420p，4K60 用 -level 5.2，默认 -crf 17，-preset medium），可以按时间段分段并行渲染再无损拼接。--scale 2 输出 3840×2160（成片用），--scale 1 输出 1920×1080（场景自检用，更快）。4K 帧必须走管道，不能存到磁盘。
- 成片交付：4K 文件较大，用 GitHub Release 交付（单个文件上限 2GB），不放进 git 仓库，所以不受 100MB 限制；画质优先，文件控制在 1.9GB 以内即可。

## 经典级标准（用户 2026-11-19 再次强调：要让大家觉得这是一个很经典的视频，特别惊艳）
做每个场景、审每个场景时都按下面这些来，不达标就继续改：
- 一个贯穿全片的视觉母题：例如一个会发光的“词”粒子从开头一直走到结尾，在每个场景里变形、汇聚、点亮。全片看起来是一个整体，不是一堆特效的拼盘。
- 色彩剧本：开头偏冷、偏暗（迷茫），逐步升温，到“恍然大悟”那一刻画面整体亮起、转暖，结尾温暖明亮。每个场景都要服从这条色彩曲线。
- 字是主角：一屏只讲一个意思，大字、留白、对比强；不堆字，不用小而密的段落。
- 电影感运镜：缓慢推拉、视差层次、前景虚化层、体积光、颗粒与暗角，营造纵深；不要平面幻灯片感。
- 动作讲究：用有性格的缓动曲线（expo、power4），有预备动作和收尾回弹，逐字错落出现；动作卡在音乐的强拍上，长音处画面舒展停留。
- 场景之间用“匹配转场”：上一个场景的形状、线条或文字变形成下一个场景的元素，而不是简单淡入淡出。
- 至少 3 个让人想截图、想倒回去再看一遍的“名场面”，例如：被遗忘的单词像瀑布一样坠落、成千上万个词连成星座拼出 English、方法卡在最后一拍整齐落定。
- 耐看的细节：第二遍看能发现第一遍没注意到的小彩蛋（例如背景里飘过的真实考研单词、曲线上的真实数据点）。
- 节奏要有呼吸：紧张处快，揭示处慢，高潮前留半拍空白再爆发。
- 结尾一句让人想在评论区引用的话，加一个值得截图收藏的定格画面。

## 全技巧工具箱（用户 2026-11-19：不能只用文字，要把所有可能用到的技巧都考虑到，挑最好的，做成最经典最好看的视频）
文字只是手段之一。每个场景至少组合 3 种手法；全片要有插画、动画、数据可视化、粒子或三维等多种形态，同时保持统一的视觉母题和色彩剧本。可用手法：
1. 矢量插画与角色：用 SVG 代码画的无脸抽象人物（剪影、线条小人、发光的点），大脑与神经元、书、耳朵、眼睛、城市夜景、桥、阶梯、种子长成树、钥匙与锁、迷宫与出口，并且让它们动起来（走、跳、发光、生长）。
2. 图形变形（MorphSVG）：一个形状变成另一个，例如单词变成星星，遗忘曲线变成一条向上的路。
3. 路径描边（DrawSVG）与沿路径运动（MotionPath）：画线、画路线、连接、追随。
4. 数据可视化：遗忘曲线、间隔复习的锯齿曲线、词汇覆盖率仪表、计数器、柱状对比；数字只用 EVIDENCE.md 里核实过的。
5. 粒子与生成艺术：成千上万个单词粒子、流场、星座、瀑布、萤火（确定性随机）。
6. 2.5D 与三维：CSS 3D 翻转卡片、透视隧道、景深层；three.js 做真正的三维名场面（例如由单词组成的旋转星球或星系），前提是 4K 渲染速度可以接受（引擎会实测）。
7. 液体、墨水、光线转场：SVG 位移滤镜（feTurbulence、feDisplacementMap）、光束扫过、遮罩擦除。
8. 文字特效：逐字弹出、打字机、乱码解码（ScrambleText）、手写描边、文字碎裂重组。
9. 界面模拟：手机背单词 App、搜索框、进度条、打卡日历（不出现真实品牌）。
10. 分屏对比：错误方法和正确方法左右并排、前后对比。
11. 光效与质感：体积光、镜头光晕、辉光、轻微色差、胶片颗粒、暗角、景深虚化。
