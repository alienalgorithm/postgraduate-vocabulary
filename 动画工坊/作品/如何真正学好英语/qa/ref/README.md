# 参考静帧

这里的 PNG 是本片在固定时刻的 1080p 画面，GitHub 上的 anim-check 工作流每次都在同样的时刻重新出图，和它们比 PSNR，确认云端出的画面和本机一模一样（字体、引擎、浏览器、CPU 差异都不许看得出来）。

文件名是 场景_t_全片秒数.png，manifest.json 记着每张图的场景、秒数和输入指纹。

## 怎么比

- 输入指纹：引擎、字体、素材、依赖锁文件、music/energy.json、这个场景的文件、分镜里这个场景和全局设置，合起来的 sha256。
- 指纹相同（这个场景没人改过）：整帧 PSNR 不低于 40 dB，并且最差的 64x64 小块不低于 28 dB，才算通过。
- 指纹不同（场景被有意改过）：不比，只提示参考图过期，不卡流程。

阈值的理由写在 动画工坊/tools/ci/stills_qa.py 开头：同一软件换 CPU 只差最低几位，PSNR 在 42 dB 以上；错一个字，那个小块会掉到 20 dB 以下。

## 什么时候更新

场景画面定了，或者有意改了画面（改场景、改分镜、换字体、升级 playwright 或引擎）以后，在仓库根目录跑：

    bash 动画工坊/tools/ci/update_refs.sh 动画工坊/作品/如何真正学好英语

要先在作品目录里 npm ci 过。不给时刻时自动选 s01 到 s05 每场字最多的那一刻，再加一个离它们最远的检查时刻；也可以自己指定场景内秒数：

    bash 动画工坊/tools/ci/update_refs.sh 动画工坊/作品/如何真正学好英语 s01:5.6,s02:3.6

出完把这个目录和画面改动一起提交。不要手改 manifest.json。
