say-en · 装机两步

模型已经在包里了，不用下载。

────────────────────────────────
1  装 Python 库
────────────────────────────────

    pip install kokoro-onnx soundfile numpy

────────────────────────────────
2  装 ffmpeg
────────────────────────────────

    Ubuntu / Debian     sudo apt install ffmpeg
    macOS               brew install ffmpeg
    Windows             ffmpeg.org 下载，解压后把 bin 加进 PATH

    验一下：ffmpeg -version

    （只用 --format wav 的话，可以不装 ffmpeg）

────────────────────────────────
跑起来
────────────────────────────────

    python say.py "Hello, this is a test."

    看到 ✓ 001.opus 就成了。

    全程离线，不需要联网，也不需要任何 API key。

────────────────────────────────

    docs/USAGE.md          每个参数、每种场景，带完整例子

    docs/PITFALLS.md       踩过的八个坑与修法
